## Architecture

- `analysis/parser.py` reconstructs and parses passive email PCAP sessions.
- `analysis/rule_engine/` provides deterministic policy findings and observations. These remain authoritative and must not be overridden by ML.
- ML consumes canonical observed features in parallel with the rule engine. Keep classifier, anomaly output, and deterministic findings separate in reports/UI.
- Threat intelligence enriches mapped findings. NIST/CWE/OWASP reference data supports remediation and explanations.
- LLM work is deferred until the user chooses the model/provider. It is for on-demand report generation and validated natural-language database queries, not packet detection.
- Preserve raw datasets. Derived datasets must record provenance, schema/version, and source type.
